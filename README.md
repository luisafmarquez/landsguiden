# 🌍 Landsguiden

Landsguiden is a responsive web application where users can explore information about countries around the world.

The project was created as part of my frontend development studies and focuses on working with React, Next.js, TypeScript, API data and responsive design.

🔗 **Live website:** https://landsguiden.vercel.app

## ✨ Features

- 🔎 Search for countries by name
- 🌍 Filter countries by region
- ⭐ Add and remove favorite countries
- ⚖️ Compare two countries
- 🏳️ View country flags
- 🏙️ View capital cities
- 👥 View population information
- 🗣️ View languages
- 📱 Responsive design for different screen sizes

## ⚖️ Compare Countries

The comparison feature allows the user to select two countries and view their information side by side.

This makes it easier to compare information such as population, capital, region and languages.

## 🛠️ Technologies

## 🚀 Deployment

The application is deployed with Vercel and connected to the GitHub repository.

Changes pushed to the `main` branch can automatically be deployed to the live website.
